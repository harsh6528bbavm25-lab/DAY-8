# Day 8 — Lab 8: Workplace Writing II

## 📌 Overview
This lab focuses on **Workplace Writing II**, with an emphasis on **summary fidelity, report scaffolding, factual accuracy, and responsible AI-assisted writing**.

The activity uses airport passenger-service and airline baggage-complaint reports to practice creating concise summaries while preserving the original meaning, numerical information, positive feedback, and source limitations.

## 🎯 Objectives
- Understand the concept of **summary fidelity**.
- Create accurate and concise management summaries.
- Verify numerical information and factual claims.
- Identify omissions, distortions, and invented information.
- Separate verified facts from assumptions and recommendations.
- Use `[VERIFY]` placeholders for information that requires confirmation.
- Develop structured management-report scaffolds.
- Review and improve AI-generated content through human verification.
